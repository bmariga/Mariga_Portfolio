Bio

I'm Mariga — a photographer, web developer, and executive assistant. Some weeks that means shooting stills around Mombasa with nothing but my phone; others it means shipping a feature or rebuilding someone's calendar from scratch. Different tools, same instinct: pay attention, build the thing properly, and don't let the details slip.

Photography is where I started noticing how much a small detail changes the whole frame — light, timing, composition. That same eye carries into how I write code and how I run someone's operations: nothing gets shipped or scheduled until it's actually right.
